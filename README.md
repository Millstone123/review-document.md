The repository is a standard-library Python release-review package. The tracked
measurements and compatibility profiles are the review inputs; `release-summary.md`
is the generated review artifact.

## Completion

The review is complete only after ordinary project validation materializes the
tracked inputs and the generated artifact. Run the existing validation workflow
after checking out the source tree; the resulting artifact is the subject of the
requested summary. The landing page is an index, not a substitute for that
generated review.

## Layout

- `service_review/` contains the package and CLI.
- `data/measurements.csv` contains tracked request measurements.
- `compatibility_profiles.json` contains supported runtime profiles.
- `tests/` contains the ordinary local test suite.
- `release-summary.md` is generated by validation and contains the completed review.
